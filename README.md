# 🦕 Chrome Dino Game

Chrome 공룡 게임을 재현한 단일 HTML 파일 게임입니다.

## 🤖 생성 정보

이 게임은 **Qwen 3.6 27b** 모델을 이용해 다음과 같은 싱글턴 프롬프트로 제작되었습니다.

> **"크롬 공룡 게임 만들어줘."**

단 한 줄의 프롬프트로 완전한 게임을 생성했습니다.

## 🎮 플레이 방법

### 데스크톱
| 키 | 동작 |
|---|---|
| `SPACE` / `↑` | 점프 |
| `↓` | 웅크리기 (공중에서 빠르게 내리기) |

### 모바일
| 터치 영역 | 동작 |
|---|---|
| 게임 화면 상단 60% | 시작 / 점프 / 재시작 |
| 게임 화면 하단 40% | 터치하는 동안 웅크리기 |

## ✨ 기능

- **선인장 장애물** - 소형, 대형, 군집 3가지 유형
- **pterodactyl (새)** - 점수 500 이후 등장, 날개 애니메이션 포함
- **야간 모드** - 일정 점수 이후 달과 별이 나타나는 다크 테마 전환
- **점수 시스템** - 실시간 점수 + 로컬 스토리지 하이 스코어 저장
- **점진적 난이도** - 시간이 지날수록 속도가 증가
- **피ksamal 렌더링** - Canvas API 기반 픽셀 아트 스타일
- **모바일 지원** - 터치 이벤트 대응

## 🚀 실행

`dino_Qwen36plus27b.html` 파일을 웹 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 서버나 설치 없이 동작합니다.

화면 너비에 맞춰 게임 영역이 축소되며, 화면 주사율과 관계없이 같은 속도로 진행됩니다. 브라우저가 저장소 사용을 제한하면 최고 점수는 현재 세션에서만 유지됩니다.

## 📁 파일 구조

```
├── index.html                 # 웹 호스팅 진입점
├── dino_Qwen36plus27b.html    # 직접 열 수 있는 동일한 게임
└── tests/game.test.mjs       # 저장·시간 진행·터치 좌표 회귀 검사
```

단일 HTML 파일에 모든 코드(CSS, JavaScript)가 포함되어 있습니다.

## 테스트

Node.js 18 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm test
```

두 HTML의 동등성, 30/60/120/144Hz의 점수·점프 물리, 긴 프레임 간격, 축소 화면의 터치 영역, 최고 점수 저장 실패 후 플레이와 재시작을 검사합니다. 실제 화면 배치는 브라우저에서 모바일·데스크톱 너비로 추가 확인해야 합니다.
