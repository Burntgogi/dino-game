# 🦕 Chrome Dino Game

Chrome 공룡 게임을 재현한 단일 HTML 파일 게임입니다.

## 🤖 생성 정보

이 게임은 **Qwen 3.6 27b** 모델을 이용해 다음과 같은 싱글턴 프롬프트로 제작되었습니다.

> **"크롬 공룡 게임 만들어줘."**

단 한 줄의 프롬프트로 완전한 게임을 생성했습니다.

## 🎮 플레이 방법

### 데스크톱
| 키 | 동작 |
|---|---|
| `SPACE` / `↑` | 점프 |
| `↓` | 웅크리기 (공중에서 빠르게 내리기) |

### 모바일
| 터치 영역 | 동작 |
|---|---|
| 화면 상단 60% | 점프 |
| 화면 하단 40% | 웅크리기 |

## ✨ 기능

- **선인장 장애물** - 소형, 대형, 군집 3가지 유형
- **pterodactyl (새)** - 점수 500 이후 등장, 날개 애니메이션 포함
- **야간 모드** - 일정 점수 이후 달과 별이 나타나는 다크 테마 전환
- **점수 시스템** - 실시간 점수 + 로컬 스토리지 하이 스코어 저장
- **점진적 난이도** - 시간이 지날수록 속도가 증가
- **피ksamal 렌더링** - Canvas API 기반 픽셀 아트 스타일
- **모바일 지원** - 터치 이벤트 대응

## 🚀 실행

`dino_Qwen36plus27b.html` 파일을 웹 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 서버나 설치 없이 동작합니다.

## 📁 파일 구조

```
└── dino_Qwen36plus27b.html   # 게임 전체 (HTML + CSS + JS)
```

단일 HTML 파일에 모든 코드(CSS, JavaScript)가 포함되어 있습니다.
